# Clústeres, navegación y recursos

## Abrir un clúster

1. Desde **Welcome/Bienvenida**, elegí **Add cluster** para importar tu kubeconfig o **Launch demo cluster** para explorar sin credenciales.
2. Seleccioná el clúster que querés inspeccionar en Catálogo o la barra de favoritos.
3. Verificá su nombre, el ambiente y el color de identificación **antes de operar**.
4. Usá la navegación lateral para acceder a **Workloads**, Pods, Deployments, Events, Networking o Kubetail, según el alcance disponible.

El clúster demo usa datos simulados. No lo confundas con un clúster real.

## Buscar recursos

Seleccioná el namespace correcto, utilizá los filtros de la tabla y abrí el detalle de un recurso. La información que ves depende de los permisos RBAC de ese clúster. Si una pantalla queda vacía, revisá clúster, namespace, conectividad y permisos.

## Kubetail y registros

Dentro del clúster, abrí **Kubetail** para revisar streams y detalles. Su área de trabajo admite **Swap**, guardado de una distribución personalizada y reordenamiento de paneles. Al restaurar sesiones, algunos streams quedan inertes hasta que los reactivás manualmente.

**Importante:** ningún paso de esta guía implica que la IA tenga permiso para ejecutar acciones o modificar recursos.
