# Acoplar, mover y agrupar paneles

**Global Docking** permite distribuir vistas dentro de una zona de trabajo. Es distinto de crear una ventana independiente del sistema.

## Organizar paneles

1. Abrí un clúster y una vista que participe de Global Docking.
2. Desde el encabezado usá **+** para agregar un panel compatible mediante el catálogo.
3. Arrastrá el encabezado hacia uno de los bordes del destino para ubicar el panel a la **izquierda, derecha, arriba o abajo**.
4. Arrastralo al área central o la pestaña destino para **agruparlo** en una misma zona.
5. Ajustá el divisor para redistribuir tamaños.

La opción de movimiento por teclado abre un menú con destinos como **Left of**, **Right of**, **Above**, **Below** y **Group with**. En ese menú se puede navegar con flechas, Home/End, Enter/Espacio y cancelar con Escape.

## Controles de encabezado

Los controles compactos pueden aparecer al pasar el puntero o al usar Tab. **−** repliega el panel, **×** lo cierra cuando está permitido y **+** abre el catálogo. La banda de recuperación devuelve un panel replegado sin recrear todo el layout.

## Restricciones

La experiencia exacta depende de la vista y del feature flag de Global Docking. No todos los paneles tienen maximizar o desacoplar, y algunos paneles de recursos solo ofrecen vistas de lectura cuando están flotantes.

Para separar una vista en una **ventana del sistema operativo**, consultá el artículo **Cómo crear una ventana flotante**.
