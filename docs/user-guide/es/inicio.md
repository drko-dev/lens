# Bienvenido a OpenLens DevOps

OpenLens DevOps permite explorar clústeres, observar recursos y organizar paneles. Esta versión incorpora **Global Docking**, ventanas independientes y un **Centro de Incidentes con diagnóstico asistido de demostración**.

## Elegí tu punto de partida

1. Para aprender a mover y organizar paneles, abrí **Acoplar, mover y agrupar paneles**.
2. Para abrir un panel en otra ventana, consultá **Cómo crear una ventana flotante**.
3. Para explorar H8, consultá **Centro de Incidentes** y **Cómo usar el diagnóstico con IA**.
4. Desde la bienvenida, podés iniciar el clúster demo sin ingresar credenciales reales.

## Distinción importante

- **Navegación y H7:** las funciones disponibles dependen del tipo de panel, del clúster y de la configuración. Los layouts pueden restaurarse sin reactivar automáticamente streams o sesiones sensibles.
- **Escáner H8:** en RC2 funciona únicamente como **Demo Sintético** con cero watchers reales.
- **IA H8:** el diagnóstico del MVP usa un **proveedor mock local**; no hace llamados reales a GPT, Claude u otros servicios.
- **Seguridad:** las propuestas de remediación no realizan cambios automáticamente en Kubernetes.

Esta guía está incluida dentro de la aplicación. No necesita conexión a internet ni un clúster conectado.
